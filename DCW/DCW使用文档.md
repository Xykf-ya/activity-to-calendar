# DCW使用文档

DCW 是 activity-to-calendar 的 Windows 版本桌面插件。它在桌面显示日程、待办和活动倒计时，可以手动记录，也可以从聊天、网页或通知中提取安排。

## 下载与启动

1. 在 GitHub 的 DCW 页面下载便携包，并将压缩包完整解压到一个文件夹。[DCW 下载页](https://github.com/Xykf-ya/activity-to-calendar/tree/main/DCW)
2. 双击解压目录中的 `Start-DCW.cmd`。请将它和 `calendar-widget.ps1` 放在同一目录。需要常用入口时，可为启动文件创建桌面快捷方式。
3. 如果已有一个 DCW 窗口，在任务栏恢复它。更新时先关闭旧窗口，再解压并启动新版。

运行环境为 Windows 10 或 11，使用系统自带的 Windows PowerShell 5.1 和 WPF。手动新增和 ICS 导入、导出可以离线使用。AI 识别需要配置 API Key 并能访问所选模型接口。截图识字使用 Windows OCR，需要系统安装对应语言的 OCR 组件。

## 查看日程与待办

- 窗口打开时显示当天。用日期两侧的箭头前后翻日，用「今天」返回当天。待办区显示截至所选日期到期的项目，以及未设截止日期的项目。
- 点「+ 新增」，选择「是」添加待办，选择「否」添加日程。待办可填写截止日期并在列表中勾选完成。勾选「显示已完成待办」可查看勾过的待办。
- 新增日程时，可选择全天或填写开始、结束时间。定时日程缺少结束时间和时长时，会弹出「补充活动时长」。可选常用时长，也可填自定义结束日期与时间，包括次日结束。
- 日期下方的倒计时每秒刷新。有日程进行时，它显示距结束的时间，进度条按活动已用时长填充。没有进行中的日程时，它显示距下一项开始的时间，进度条在开始前 24 小时内逐步填满。
- 按住顶部标题区拖动窗口。打开「⋯ → 外观设置」，可调整面板和强调色、不透明度、系统字体、字号、宽度与高度。调整时可以实时预览，点「应用」保存。

## 配置 AI 接口

打开「⋯ → API 设置」，填写以下内容，然后点「保存」。

| 设置 | 填写方式 |
| --- | --- |
| API 地址 | 完整的 OpenAI 兼容 Chat Completions 地址，包含路径和服务所需的端口。默认 `https://api.deepseek.com/chat/completions`。 |
| 模型名称 | 服务商提供的模型 ID。默认 `deepseek-chat`。 |
| API Key | 在模型服务商处创建的 Key。已有 Key 时留空可保留，点「清除 Key」可删除。 |

自建服务可以使用 `http://localhost:8000/v1/chat/completions` 这样的地址，端口和路径按实际服务填写。接口需接受 Bearer 认证和 `response_format: {"type":"json_object"}` 请求参数，并返回 Chat Completions 格式的结果。DCW 发出请求，端口由所配置的服务提供。

## 从其他应用识别

### 框选识别

1. 在浏览器、聊天软件或其他应用中打开通知，让日期、时间、地点等文字都显示在屏幕上。
2. 点击组件的「框选识别」，在截图层按住鼠标左键拖出范围，再松开。按 `Esc` 或点右键可取消。
3. Windows 在本机从所选截图提取文字，然后 DCW 将识别出的文字发送给配置的模型。模型返回的事项通过校验后自动保存到本机列表，重复项会跳过。遇到缺少时长的定时日程，先在弹窗中补齐。

### 粘贴识别

复制通知文字，点「粘贴识别」，在预览中核对或编辑文字，点「识别安排」。查看模型整理的事项，确认后保存。

可用一条虚构通知熟悉流程，例如「明天下午 2 点在图书馆讨论小组分工，预计 35 分钟」。原文提供明确时长时，组件据此计算结束时间。对于日期或时间有歧义的通知，可先在文字中写清楚再识别。

## 数据与日历交换

- 日程和待办存放在 `%LOCALAPPDATA%\X-Crea\CalendarWidget\items.json`，外观和接口设置存放在同目录的 `settings.json`。通常换用新版启动文件会继续读取该目录。
- API Key 用 Windows DPAPI 为当前用户加密，保存在 `api-key.bin`。更换电脑或 Windows 用户后，在新环境重新填写 Key。
- 在「⋯」菜单中选择「导入日历（ICS）」或「导出日历（ICS）」，可与支持 `.ics` 文件的日历应用交换数据。重复日程只导入起始实例。DCW 使用本机列表，需要在其他日历中使用时可导出并导入到对应应用。
- 框选发送 OCR 提取的文字。粘贴识别发送你在预览中提交的内容。使用在线模型时，所提交的文字会发往你设置的接口，请按需缩小框选区域或在预览中删去敏感信息。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 双击后没有出现窗口 | 确认压缩包已完整解压、启动文件与 PowerShell 脚本在同一目录。检查任务栏是否已有组件窗口。 |
| 框选报错或没有识别到文字 | 确认 Windows 已安装相应语言的 OCR 组件，尽量选择清晰文字。也可复制原文并用「粘贴识别」。 |
| 接口报错或一直等不到结果 | 检查完整 API 地址、端口、模型名、Key、账户额度和网络。自建服务还需确认已启动且支持 Chat Completions JSON 模式。 |
| 新增事项后列表没显示 | 用日期箭头查看对应日期，或检查待办是否已完成。窗口底部会显示识别或保存状态。 |
